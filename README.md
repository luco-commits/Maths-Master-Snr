# Maths Master Snr V2

A responsive, installable Queensland mathematics study platform for Years 7 to 12.

## Key features

- Study and Exam modes
- Course areas aligned to Queensland Years 7 to 10 curriculum structure
- Senior pathways for Essential Mathematics, General Mathematics, Mathematical Methods and Specialist Mathematics
- Structured working, immediate checking and worked solutions
- Formula reference panel
- Local progress and best-result tracking
- Responsive phone, tablet and desktop design
- Offline PWA support

## GitHub Pages

Upload all files and folders to the repository root. In Settings > Pages, deploy the main branch from /(root).

After updating, open the site once in the browser so the service worker can install the new cache.
